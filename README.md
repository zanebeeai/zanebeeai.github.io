# zanebeeai.github.io

- `/` redirects to https://zanebeeai.com/
- `/rigby/` is the Rigby kinematic motion dataset site (built from the rigby repo by `docs/preprint/kinematic/release/publish_pages.sh`; data on Hugging Face at rigby-robotics/rigby-kinematic)
- `/rigby-alt/` is an alternative design of the same site; it reads the data, records and videos of `/rigby/`
